# 🪵 UnstripLog

**UnstripLog** is a lightweight Fabric mod for Minecraft 1.21.5+ that lets you reverse stripped logs back into regular logs using a custom item called **Bark**. Also adds a Bark-to-Paper crafting mechanic!

---

## 📦 Features

- ✅ Right-click stripped logs with **Bark** to restore them
- ✅ Craft **Paper** from Bark (horizontal recipe only)
- ✅ Bark is usable as **fuel**
- ✅ Lightweight and easy to integrate

---

## 🔧 Requirements

- Minecraft `1.21.5+`
- Fabric Loader `>=0.15.0`
- [Fabric API](https://modrinth.com/mod/fabric-api)
- Java `17+`

---

## 📥 Installation

1. Download from [-]
2. Drop the `.jar` into your Minecraft `mods/` folder
3. Launch the game with Fabric
